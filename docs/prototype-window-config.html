10-Day Forecast
Prototype — illustrative mock data. The Available Time Window is dashboard-wide (one range for all 10 days), defaults to widest daylight coverage (floor(earliest sunrise) → ceil(latest sunset)), and highlights its interval: hours outside it stay visible but dimmed. A day's badge = the best status of any contiguous demo-length block that fits inside the window — so narrowing the window or lengthening the demo can flip a day to NO-GO. We never name a "best" window; choosing the exact block stays Tara's call.
