Where do the weather icons go?
Typical weather apps show a little sun / cloud / rain glyph per day and per hour. This explores where to place that icon on our two surfaces — the 10-day strip and the hourly detail — with three options each. The icon is purely informational (it never changes go/no-go; status still comes only from wind, wave, rain, and visibility), so it's a second colour layer sitting next to the green/amber/red status. Night hours are already dropped, so these are all daytime icons.
How to read this
The coloured bar/segments are status (green = go, amber = caution, red = no-go). The weather glyph is the sky condition (sun, cloud, rain…). The same mock 10-day forecast and the same example day drive every option below, so you're comparing placement, not data. Pick the layout that reads fastest to you.
A · 10-day strip — one icon per day
Each day's icon shows its most notable condition (a day that rains in the afternoon shows the rain icon, even if the morning is clear) — same "worst wins" idea we use for status.
B · Hourly detail — one icon per hour
Same example day in all three: clear morning → cloud builds → rain → a stormy close, so the icon changes row to row.
