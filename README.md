# Saronic Weather Dashboard

A 10-day demo weather look-ahead for **Gulfport, MS** — a one-page dashboard that gives a
quick go/no-go read on whether conditions support running an autonomous-vessel customer demo.

## Tech stack

- **React** + **TypeScript**
- **Vite** (dev server / build tooling)

> Planned: MUI, Redux Toolkit, and RTK Query for UI, state, and cached data fetching.

## Getting started

Requires Node 18+ and npm.

```bash
npm install      # install dependencies
npm run dev      # start the dev server (http://localhost:5173)
npm run build    # type-check and build for production
npm run preview  # preview the production build locally
npm run lint     # run ESLint
```
